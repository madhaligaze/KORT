# KORT для Windows

Тот же KORT, что на kort.cards, но работает и тогда, когда сервер лежит или
пропал интернет: показывает данные на момент потери связи и принимает правки
договоров, которые уйдут на сервер сами, когда связь вернётся.

## Как устроено

```
окно KORT ──► шлюз 127.0.0.1:47823 ──► страницы: локальный фронт (тот же Next, что у сайта)
                    │
                    └──► /api/backend/*: kort.cards → прямой адрес API
                         ответы на чтение - на диск (шифр Windows),
                         без связи - отдаются с диска
```

| Файл | Что делает |
| --- | --- |
| `src/main.ts` | запуск, окно, мост, значок |
| `src/gateway.ts` | шлюз: связь, сохранённые ответы, реестр свежим по опросу |
| `src/vault.ts` | шифрованное хранилище (`safeStorage` = DPAPI) |
| `src/web.ts` | локальный фронт отдельным процессом |
| `src/updates.ts` | обновления из релизов GitHub |
| `src/preload.ts` | `window.kortDesktop` для страницы |

Сторона страницы: `src/components/desktop/` (мост, строки «нет связи» и
«Обновите приложение», окно устаревшей версии) и очередь в
`src/components/finance/contracts/store.ts` (раздел «Без связи»).

## Что работает без связи

- Открыть KORT (если на этом компьютере уже входили) и всё, что открывалось
  или читалось заранее: реестр, карточки, кабинет.
- Править поля договоров и заводить новые договоры. Очередь лежит на диске и
  переживает закрытие окна; поле, которое за это время поменял другой, не
  перезаписывается молча - это конфликт со словами в карточке и листе.
- Остальные действия (настройка реестра, доли, удаление, счета) без связи
  отвечают «Без связи это не выполнить». Договор, заведённый без связи и ещё
  не отправленный, удаляется сразу.

Войти впервые без связи нельзя: сохранённое привязано к сеансу.

## Обновления

Каждый пуш в `main`, который трогает `src/`, `public/`, `desktop/` или
зависимости сайта, собирает установщик (`.github/workflows/desktop.yml`) и
выкладывает его релизом репозитория. KORT у людей сам скачивает новую
версию и показывает «Обновите приложение»; нажали - закрылся и открылся
новым.

Версия - `уровень.0.номер_сборки`, уровень - в `release.json`. **Поднимите
уровень, когда старой версией работать уже нельзя** (сервер ждёт от
клиента другого, сменился смысл полей, очередь правок старой версии
навредит). Тогда у всех старых версий - окно «Эта версия KORT устарела» без
«Позже». Улучшения интерфейса и правки сервера, совместимые со старым
клиентом, уровень не поднимают.

## Локально

```
cd desktop
pnpm install
pnpm web                                  # собрать фронт сайта и разложить в web/
KORT_API=http://127.0.0.1:8080 pnpm start # против локального API
pnpm dist                                 # установщик в release/ без выкладки
```

`KORT_API` - адреса API через запятую; `KORT_DATA_DIR` - своя папка данных
(проверки не трогают сохранённое настоящего KORT). Из терминала VS Code
снимите `ELECTRON_RUN_AS_NODE`, иначе Electron запустится как Node.

Журнал - `%APPDATA%\KORT\logs\kort.log`. Проверки -
`Documents\pw-finmap\kort\desktop-1023\` (`smoke.cjs`, `queue.cjs`).
